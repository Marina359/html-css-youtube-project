# YouTube Clone (HTML/CSS)

A front-end recreation of the YouTube homepage, built as a self-directed training project to practice HTML structure and CSS layout.

## About

This project was built in 2023 while I was self-teaching front-end fundamentals, before starting my professional design career. The goal was to practice translating a real, complex interface into clean HTML and CSS — working through layout, spacing, typography, and responsive structure.

## What I practiced

- Semantic HTML structure
- CSS layout techniques (flexbox/grid)
- Responsive design fundamentals
- Recreating an existing visual design accurately from scratch

## Note

This is a personal training exercise, not an official or commercial product. It is not affiliated with, endorsed by, or connected to YouTube or Google in any way. Built for learning purposes only.
